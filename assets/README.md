# Aset Prolog KALA

Folder ini berisi aset yang dipakai alur sekarang dan dua paket persiapan doomsday.
PNG/resource aktif dipertahankan di path aslinya; tidak ada perubahan piksel atau atlas.

## Aktif sekarang

24 PNG: 8 karakter, 4 apartemen, 5 jembatan, 3 kedai, dan 4 UI.
Scene utama: `scenes/prolog/prolog_flow.tscn`.

## Persiapan doomsday — belum dipasang ke gameplay

- `sprites/backgrounds/prolog/bridge/disaster_v01/`: jembatan rusak, latar dan rintangan.
- `sprites/characters/saka/actions_v01/`: sprite sprint, jump dan slide beserta preview/revisi.

Kedua paket dipertahankan utuh karena pengerjaan asetnya masih berlangsung.
Fase kabur di alur saat ini masih memakai placeholder yang sudah terpasang.

## Versi lama

Draft dan resource lama di luar paket persiapan telah dipindahkan ke `work/asset_archives/`.
Setiap arsip menyertakan `unused_assets.zip`, daftar path asli dan checksum.
Untuk memulihkan, ekstrak ZIP ke root project dengan path `assets/...` yang sama.
Folder `work/` tidak masuk Git sesuai `.gitignore` project.
